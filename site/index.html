What is being compared?

Left score: the first map versus the right-hand baseline, using the first map’s 0-to-maximum display bounds. Right score: the middle map versus that same displayed baseline. Both account for clipping and color saturation. With No normalization and matching observed display bounds, the scores match. Unclipped correlations are retained below. Normalization applies only to the observation. In normalized modes, this is a correlation between different representations, not a like-for-like prediction accuracy score. Both use the native bins currently visible at the selected resolution. Zooming and panning change the scored region; changing bin width or source-window span loads the corresponding data. Mirrored pairs count once, including the actual diagonal when visible. Nonfinite and missing pairs are excluded. Changing a display limit updates the corresponding score; affine color rescaling alone leaves Pearson unchanged.

Methods, background definitions and private sharing

1 · No normalization: ln(1 + O), where O is the raw PET count. All methods start from the same raw counts aggregated before transformation. Actual diagonal counts and supported zeros remain included. No ICE/KR, adaptive coarse-graining or contact-map smoothing is used.

2 · Shared observed distance: E(d) = all-chromosome raw PET total at separation d / supported unique pair opportunities at d, including zeros. This is a raw-count expectation, distinct from a baseline fitted to mean ln(1 + counts).

3 · Shuffled endpoints: endpoints are re-paired within each chromosome in ten seeded rounds using the pinned cLoops2 estDis implementation. Shuffled distance histograms are pooled and divided by supported pair opportunities. This per-pixel conversion is our map adaptation of the green distance-frequency graph.

4 · Dense PLB adaptation: each endpoint shifts by −5…−1 or +1…+5 output bins. Average counts across unique eligible nearby unordered pairs; retain zeros and actual diagonal counts, exclude the central pair and reversed duplicates. Chromosome halos supply neighbors outside the displayed window. The stabilized option uses E = max(B, 1)/n; the unmodified option uses E = B/n. No neighbors means undefined. This fixed-bin construction follows the original cLoops local-background idea; it is not the complete loop caller.

5 · Within-window distance: raw-count means over supported pairs, using cooltools nearby-distance groups (ratio 1.03). Computed over the entire selected 1-, 2- or 4-Mb window, then retained when zooming. Akita-inspired, without Akita’s balancing, coarse-graining, interpolation, clipping or smoothing.

Shared normalization references are descriptive and include inspected chromosomes. PLB and within-window backgrounds depend on the observed map. They are not supplied to the predictive baseline. The third panel retains the frozen endpoint spline/ridge baseline in its original log-map units, with display clipping only. No expected background is applied to it, and it is not logged a second time. Its color scale matches the middle observed panel. The first panel keeps the original observed log counts as a reference.

Each model uses a distance intercept plus a symmetric adjustment for DNase at both endpoints. Existing 1-, 2- and 5-kb models are from the completed large-window campaign; 10-kb models use the same fitting windows. The 1-Mb views reuse the frozen 2-Mb model coefficients at the same bin width; they are evaluations on smaller regions, not newly fitted models. None fits chr3/chr4 contacts. Other displayed chromosomes include baseline fitting chromosomes; these exploratory correlations are not a new held-out evaluation. A baseline cell is unavailable if either endpoint lacks complete DNase coverage. Baseline metrics use common supported pairs, include zeros and the actual diagonal, and are recalculated after the selected clipping in the comparison card.

For ln(O/E), zero counts with E > 0 remain −∞. Positive counts with E = 0 are +∞; 0/0 or unavailable expectations are undefined. These categories render white and are counted separately. They are never silently moved into finite clipping bins. For ln(1 + O/E), O = E corresponds to ln(2), not zero.

There are 5,372 complete coordinate windows across all 24 nuclear chromosomes, at each of four bin widths: 21,488 maps. ChrY lacks the verified DNA-reference support and is explicitly masked; chrM has no cis matrix and no complete 1-Mb window. Incomplete chromosome tails are excluded. Support is the existing reference-availability mask, not a full mappability assessment. Overview rendering samples native cells without smoothing; zoom to resolve individual bins.

Displayed PCC: The first score compares clip(ln(1 + O), 0, raw maximum) with the displayed baseline. The second compares the displayed selected transformation T(O) with that same baseline. The middle and right maps apply the chosen minimum/maximum, then saturation at their color-scale limits. Native values after these operations determine the scores; positive affine color rescaling does not change Pearson. No normalization with matching observed display bounds gives identical scores. The original unclipped corr(ln(1 + O), B) and the selected-transformation unclipped correlation remain under “What is being compared?” and in settings exports. B is the original signed log-map prediction, never divided by E or logged again. In normalized modes the middle map and baseline represent different quantities; their correlation describes the displayed patterns, not normalized prediction accuracy. Both scores use common supported unique unordered pairs intersecting the visible viewport. Mirrored pairs count once, partially visible edge bins and the actual diagonal are included. Nonfinite values are excluded before clipping, never converted to finite boundary values. Each score reports its retained pair count. Literal ln ratios exclude zero observations. Native Float32 map values are used, not sampled screen pixels or quantized colors. PCC is undefined for constant maps or fewer than two pairs. Normalization backgrounds remain defined on the complete selected window or chromosome; zoom only changes the scored region.
