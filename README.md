# Viewer — private K562 contact-map explorer

[Open the private Viewer](https://fantastic-giggle-km2w1lq.pages.github.io/)

Sign in with a GitHub account that can read this repository. This is a private GitHub Pages project site in the Tuan-hosts Enterprise organization. Copying its link does not grant access.

**21,488 maps** across all 24 nuclear chromosomes: 1/2/5/10-kb bins × 1/2/4-Mb windows. ChrY is explicitly masked because the reference support is unavailable; chrM has no usable matrix. The baseline remains the frozen original signed log-map prediction.

See [methods](site/README.md) and [validation](site/VALIDATION_REPORT.md). The original personal repository is preserved. Other server jobs, training stages and historical files were not modified.

Deployments verify the reviewed package hashes and require both repository and Pages visibility to remain private. All map data are served from the private Pages origin.
